This project is a C application developed as part of the **SE 133 – Software Development Capstone Project**. It provides a role-based system for managing employee records, attendance tracking, and payroll processing, with all data persisted using plain text files.

## 👥 Team Roles

This project is divided into three modules, one per team member. Each member is responsible for implementing the menu, logic, and file operations for their assigned role.

## ✨ Features

### HR / Admin
-Functionalities:
-Add new employee records
-Update existing employee details
-Delete / deactivate employee records
-Search for employees (by ID)
-View all employees (grouped by role)
-Record daily attendance
-View attendance records (all or by employee)
-Update attendance records
-Calculate monthly salary based on attendance
-Generate payroll (with bonus & deductions)
-View payroll information (all or by employee)
-HR portal menu


### Manager
-View all employees (grouped by role)
-View attendance records (all or filtered)
-View payroll information (all or filtered)
-Manager portal menu

### Employee
-View own profile / information
-View own attendance history
-View own payroll / payslip information
-Employee portal menu

## 🛠️ Tech Stack

- **Language:** C (C99 / GNU C)
- **Data Storage:** Plain text files (`.txt`)
- **Build Tool:** GCC Compiler
